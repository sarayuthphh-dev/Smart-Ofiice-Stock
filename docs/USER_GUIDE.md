# คู่มือใช้งานฉบับย่อ

## เจ้าหน้าที่ผู้เบิก

1. เข้าเมนู **เบิกวัสดุ** ระบุวัตถุประสงค์ เพิ่มวัสดุและจำนวนได้หลายรายการ
   วัสดุที่ยอดเป็นศูนย์จะแสดง **หมดสต๊อก — เบิกไม่ได้** และไม่สามารถเลือกได้ หากยอดหมดหลังบันทึกแบบร่าง ระบบจะปฏิเสธตอนส่งคำขอและให้แก้รายการก่อน
2. เลือก **บันทึกแบบร่าง** เพื่อกลับมาแก้ หรือ **ส่งคำขอ** เพื่อส่งอนุมัติ ยอดคงเหลือที่เห็นยังไม่ใช่การจอง
3. ติดตามเลขคำขอ สถานะ และเหตุผลส่งกลับ/ไม่อนุมัติใน **คำขอของฉัน** แบบร่างและรายการส่งกลับแก้ไขได้ คำขอก่อนอนุมัติยกเลิกได้
4. หลังรับของ เข้า **ยืนยันรับของ** แล้วกดยืนยันเฉพาะเอกสารที่ได้รับจริง การกดนี้ไม่ตัดสต๊อกอีกครั้ง
5. หากยังมีใบจ่ายที่ไม่ได้ยืนยัน ระบบจะแสดงจำนวนค้างที่เมนูและแจ้งเตือนบนหน้า Dashboard คำขอจะเปลี่ยนเป็น **เสร็จสมบูรณ์** เมื่อยืนยันรับครบทุกใบจ่ายแล้วเท่านั้น

## ผู้อนุมัติ

1. เข้า **อนุมัติคำขอ** เปิดรายการ ตรวจวัตถุประสงค์ จำนวนขอและยอดคงเหลือขณะนั้น
2. ปรับจำนวนอนุมัติได้แต่ห้ามเกินจำนวนขอ แล้วเลือกอนุมัติ ส่งกลับ หรือไม่อนุมัติ การส่งกลับ/ไม่อนุมัติต้องมีเหตุผล
3. การอนุมัติไม่จองและไม่ตัดสต๊อก ยอดจริงอาจเปลี่ยนก่อนเจ้าหน้าที่พัสดุจ่าย

## เจ้าหน้าที่พัสดุ

- **จ่ายวัสดุ:** กรอกจำนวนจริงและชื่อผู้รับ ระบบ lock สต๊อกและไม่ยอมให้ติดลบ จ่ายบางส่วนและกลับมาจ่ายเพิ่มได้ หรือปิดยอดค้างพร้อมเหตุผล
- **ทะเบียนวัสดุ:** เข้า **คลังวัสดุและรับเข้า** กด **เพิ่มวัสดุ** เพื่อสร้างรายการใหม่ หรือคลิกชื่อวัสดุเพื่อแก้ไข รายการที่มีประวัติให้ปิดสถานะแทนการลบ
- **นำเข้า CSV:** กด **นำเข้า CSV** แล้วดาวน์โหลดแม่แบบ กรอกข้อมูลและบันทึกเป็น CSV UTF-8 รหัสใหม่จะถูกเพิ่ม ส่วนรหัสเดิมจะถูกปรับปรุง การนำเข้าไม่เปลี่ยนยอดคงเหลือ
- **รับเข้า:** เลือกวัสดุ จำนวนหน่วยพื้นฐาน วันที่ แหล่งที่มา และเอกสารอ้างอิง การตั้งต้นหลังนับจริงให้ทำเครื่องหมาย “ยอดตั้งต้น”
- **คืนวัสดุ:** อ้างอิงรายการจ่าย กรอกสภาพดีและชำรุดแยกกัน เฉพาะสภาพดีจะกลับเป็นยอดพร้อมเบิก
- **ตรวจนับ:** สร้างรอบก่อนลงนับ กรอกยอดจริงและเหตุผลเมื่อมีผลต่าง หากมี movement แทรกระบบจะไม่ยืนยันและต้องสร้างรอบใหม่
- **แก้รายการผิด:** ห้ามแก้ ledger โดยตรง ใช้รายการกลับรายการโดยระบุเหตุผล (ปัจจุบันใช้ service/API ภายใน; ให้ผู้ดูแลฐานข้อมูลดำเนินการตามขั้นตอนควบคุม)

## ผู้ดูแลระบบ

สร้างกลุ่มงานและบัญชี กำหนดได้หลายบทบาทต่อบัญชี รหัสผ่านต้องมีอย่างน้อย 6 ตัวอักษร แก้ไขบทบาทภายหลังได้ หากมีประวัติให้เอาเครื่องหมาย “เปิดใช้งาน” ออก ห้ามลบบัญชีจากฐานข้อมูล ตั้ง Base URL ใน `config/config.php` ก่อนพิมพ์ QR

เมนู **ตั้งค่าระบบ** แยกเป็น 6 หน้าตามงาน ได้แก่ **ชื่อและโลโก้**, **เมนูและรายงาน**, **รูปแบบใบเบิก**, **บัญชีผู้ใช้**, **กลุ่มงาน** และ **แจ้งเตือน LINE** ไม่รวมแบบฟอร์มทั้งหมดไว้หน้าเดียว

ใน **ตั้งค่าระบบ → ชื่อและโลโก้** ผู้ดูแลสามารถแก้ชื่อระบบ ชื่อสำนักงาน คำนำหน้าเลขคำขอ เลือกโทนสี และอัปโหลดโลโก้ JPEG/PNG/WebP ขนาดไม่เกิน 2 MB ได้ โลโก้จัดเก็บนอก Web Root และระบบตรวจชนิดไฟล์จริงก่อนใช้งาน การเปลี่ยนแปลงถูกบันทึกใน Audit Log

ใน **ตั้งค่าระบบ → เมนูและรายงาน** สามารถเปลี่ยนชื่อเมนู เปิด/ปิดการแสดง และกำหนดลำดับภายในหมวดได้ เมนูภาพรวมและเมนูและรายงานบังคับแสดงเพื่อป้องกันการเข้าถึงหน้าตั้งค่าไม่ได้ การซ่อนเมนูไม่ใช่การถอนสิทธิ์ ผู้ใช้ยังถูกตรวจบทบาทฝั่งเซิร์ฟเวอร์ตามเดิม

สำหรับรายงาน ผู้ดูแลกำหนดข้อความหัว/ท้ายรายงาน ชื่อช่องผู้จัดทำและผู้ตรวจสอบ การแสดงโลโก้ และกระดาษแนวตั้งหรือแนวนอนได้ ค่าจะใช้กับรายงานการเพิ่มวัสดุและรายงานการเบิก/จ่ายที่เปิดเพื่อพิมพ์หรือบันทึก PDF

ใน **ตั้งค่าระบบ → รูปแบบใบเบิก** ผู้ดูแลกำหนดชื่อเอกสาร ข้อความใต้ชื่อสำนักงานและส่วนท้าย ชื่อข้อมูล/คอลัมน์ ช่องลงนาม การแสดงโลโก้ และการแสดงสถานะได้ มีปุ่มเปิดตัวอย่างคำขอล่าสุดก่อนนำไปใช้งานจริง

ใน **ตั้งค่าระบบ → แจ้งเตือน LINE** ผู้ดูแลกำหนด LINE User ID ของเจ้าหน้าที่พัสดุได้สูงสุด 20 บัญชี ดูสถานะ token เปิด/ปิดระบบ ส่งข้อความทดสอบ และตรวจประวัติการส่งล่าสุด Channel Access Token ต้องตั้งใน configuration หรือ environment และจะไม่แสดงกลับบนหน้าจอ เจ้าหน้าที่ต้องเพิ่ม LINE Official Account ของสำนักงานเป็นเพื่อนก่อนรับข้อความ

## การพิมพ์และรายงาน

หน้าแต่ละคำขอมีปุ่ม **พิมพ์ใบเบิก A4** ใช้คำสั่ง Print ของเบราว์เซอร์เพื่อพิมพ์หรือ Save as PDF

ในเมนู **รายงาน** ตั้งตัวกรองก่อน แล้วกด **PDF การเพิ่มวัสดุ** หรือ **PDF การเบิก/จ่าย** ระบบจะเปิดรายงาน A4 แนวนอนในแท็บใหม่ กด **พิมพ์ / บันทึก PDF** และเลือก Save as PDF ในเบราว์เซอร์ รายงานส่งออก CSV มี UTF-8 BOM สำหรับ Excel และป้องกันค่าที่ Excel อาจตีความเป็นสูตร
