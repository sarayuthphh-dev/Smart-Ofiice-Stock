## 1. ภาพรวมของระบบ

ระบบใช้บริหารการเบิกและคลังวัสดุสำนักงานแบบครบวงจร โดยมีความสามารถหลักดังนี้

- สร้างคำขอเบิกวัสดุได้หลายรายการในเอกสารเดียว
- บันทึกคำขอเป็นแบบร่าง แก้ไข ส่งอนุมัติ ส่งกลับ และยกเลิกได้ตามสถานะ
- อนุมัติเต็มจำนวน บางส่วน หรือไม่อนุมัติแยกรายการได้
- จ่ายวัสดุเต็มจำนวนหรือหลายครั้งแบบจ่ายบางส่วน โดยตัดสต๊อกเมื่อยืนยันจ่ายจริงเท่านั้น
- ให้ผู้เบิกยืนยันรับของแต่ละใบจ่าย เพื่อปิดกระบวนการอย่างสมบูรณ์
- รับวัสดุเข้า บันทึกยอดตั้งต้น คืนของ แยกของดี/ชำรุด และตรวจนับเพื่อปรับยอด
- เก็บ Stock Movement Ledger และประวัติการดำเนินการเพื่อสอบย้อนกลับ
- ตรวจสอบว่ายอดคงเหลือตรงกับ Ledger และส่งออกผลเป็น CSV
- จัดการทะเบียนวัสดุ รูปภาพ หมวดหมู่ หน่วย ตำแหน่ง และยอดขั้นต่ำ
- นำเข้าทะเบียนวัสดุจำนวนมากด้วย CSV โดยไม่กระทบยอดคงเหลือ
- ติดตามอุปกรณ์ใช้ซ้ำว่าอยู่กับผู้ใช้รายใด
- แสดง Dashboard งานค้าง วัสดุใกล้หมด แนวโน้ม และข้อมูลเชิงบริหาร
- ออกรายงาน ค้นหา กรอง ส่งออก CSV พิมพ์เอกสาร หรือบันทึก PDF
- แจ้งคำขอและผลการดำเนินงานผ่าน LINE Official Account
- กำหนดผู้ใช้หลายบทบาท กลุ่มงาน ชื่อระบบ โลโก้ สี เมนู และรูปแบบเอกสารได้

หลักสำคัญของระบบคือ “อนุมัติไม่เท่ากับตัดสต๊อก” ยอดจะลดลงเมื่อเจ้าหน้าที่พัสดุกด **ยืนยันจ่ายและตัดสต๊อก** เท่านั้น

## 2. บทบาทและสิทธิ์ผู้ใช้

บัญชีหนึ่งบัญชีมีได้หลายบทบาท เมนูที่เห็นจึงเป็นผลรวมของทุกบทบาทที่ได้รับ

| ความสามารถ | ผู้เบิก | ผู้อนุมัติ | เจ้าหน้าที่พัสดุ | ผู้ดูแลระบบ |
|---|:---:|:---:|:---:|:---:|
| ดูหน้า Dashboard | ✓ | ✓ | ✓ | ✓ |
| สร้างและติดตามคำขอของตน | ✓ | – | – | – |
| ยืนยันรับของ | ✓ | – | – | – |
| พิจารณาอนุมัติคำขอ | – | ✓ | – | – |
| จ่าย คืน รับเข้า และตรวจนับ | – | – | ✓ | – |
| จัดการทะเบียนวัสดุ | – | – | ✓ | ✓ |
| ดูรายงาน | – | ✓ | ✓ | ✓ |
| กลับรายการ Stock Movement | – | – | ✓ | – |
| ตรวจความถูกต้องของสต๊อก | – | – | ✓ | ✓ |
| จัดการผู้ใช้ กลุ่มงาน และตั้งค่า | – | – | – | ✓ |

หมายเหตุ: การซ่อนเมนูในการตั้งค่ามีผลเฉพาะการแสดงผล ไม่เปลี่ยนสิทธิ์จริง ฝั่งเซิร์ฟเวอร์ยังตรวจบทบาททุกครั้ง

## 3. การเข้าสู่ระบบและหน้าแรก

### 3.1 เข้าสู่ระบบ

1. เปิด URL ของระบบที่สำนักงานกำหนด
2. กรอกชื่อผู้ใช้และรหัสผ่าน
3. กด **เข้าสู่ระบบ**
4. หากเข้าไม่ได้ ให้ตรวจภาษาแป้นพิมพ์ ตัวพิมพ์เล็ก/ใหญ่ หรือให้ผู้ดูแลตรวจว่าบัญชียังเปิดใช้งานอยู่

เมื่อใช้งานเสร็จควรกด **ออกจากระบบ** มุมขวาบน โดยเฉพาะเมื่อใช้เครื่องร่วมกัน

### 3.2 หน้า Dashboard

หน้า **ภาพรวม** แสดงข้อมูลตามสิทธิ์ของผู้ใช้ ได้แก่

- จำนวนคำขอรออนุมัติ
- จำนวนคำขอรอจ่ายหรือจ่ายบางส่วน
- จำนวนคำขอที่ส่งในเดือนปัจจุบัน
- จำนวนวัสดุที่เหลือต่ำกว่าหรือเท่ากับยอดขั้นต่ำ
- รายการวัสดุใกล้หมดหรือหมด
- วัสดุที่มีการเบิกบ่อยใน 90 วัน
- ปุ่มลัดตามบทบาท เช่น สร้างคำขอ อนุมัติ จ่ายของ และเปิดคลัง
- สำหรับผู้มีสิทธิ์รายงาน จะแสดงข้อมูลเชิงบริหารช่วง 6 เดือนล่าสุด
- สำหรับผู้เบิก จะแสดงคำเตือนเมื่อมีใบจ่ายที่ยังไม่ได้ยืนยันรับ

Dashboard เป็นข้อมูลสรุปเพื่อช่วยติดตามงาน ไม่ใช่หลักฐานแทนเอกสารรายละเอียด ให้คลิกเมนูหรือเลขคำขอเพื่อดูข้อมูลฉบับเต็ม

## 4. กระบวนการเบิกวัสดุ

ลำดับงานปกติเป็นดังนี้

1. ผู้เบิกสร้างคำขอและเลือกวัสดุ
2. ผู้เบิกบันทึกแบบร่างหรือส่งคำขอ
3. ผู้อนุมัติอนุมัติ ส่งกลับแก้ไข หรือไม่อนุมัติ
4. เจ้าหน้าที่พัสดุจัดของ และเลือกแจ้งผู้เบิกว่า “พร้อมรับ” ได้
5. เจ้าหน้าที่พัสดุบันทึกจำนวนที่จ่ายจริง ระบบจึงตัดสต๊อก
6. หากจ่ายไม่ครบ สามารถจ่ายเพิ่มในภายหลังหรือปิดยอดค้างพร้อมเหตุผล
7. ผู้เบิกยืนยันรับของทุกใบจ่าย
8. เมื่อจ่ายเสร็จและยืนยันรับครบ ระบบระบุคำขอเป็น **เสร็จสมบูรณ์**

ยอดคงเหลือที่เห็นขณะสร้างหรืออนุมัติเป็นยอด ณ เวลานั้น ระบบไม่จองของไว้ จึงอาจเปลี่ยนก่อนถึงเวลาจ่ายจริง

## 5. คู่มือสำหรับผู้เบิก

### 5.1 สร้างคำขอเบิก

1. เข้าเมนู **งานเบิกวัสดุ → เบิกวัสดุ**
2. ระบุวัตถุประสงค์ให้ชัดเจน เช่น ชื่องาน กิจกรรม หรือเหตุผลที่ต้องใช้
3. ค้นหาและเลือกวัสดุที่ต้องการ สามารถเพิ่มหลายรายการในคำขอเดียว
4. กรอกจำนวนเป็นหน่วยพื้นฐานที่แสดง เช่น ด้าม รีม กล่อง หรือม้วน
5. ตรวจรายการซ้ำและจำนวนก่อนบันทึก
6. เลือกอย่างใดอย่างหนึ่ง
   - **บันทึกแบบร่าง**: เก็บไว้แก้ไขภายหลัง ยังไม่ส่งให้ผู้อนุมัติ
   - **ส่งคำขอ**: สร้างเลขคำขอและส่งเข้าสู่คิวอนุมัติ

วัสดุที่ยอดเป็นศูนย์จะแสดงว่า **หมดสต๊อก — เบิกไม่ได้** และเลือกไม่ได้ หากยอดหมดหลังจากบันทึกแบบร่าง ระบบจะตรวจอีกครั้งตอนส่งและแจ้งให้แก้รายการ

### 5.2 ติดตาม แก้ไข หรือยกเลิก

1. เข้าเมนู **คำขอของฉัน**
2. คลิกเลขคำขอ หรือ “แบบร่าง #...” เพื่อดูรายละเอียด
3. หน้ารายละเอียดแสดงวัตถุประสงค์ จำนวนที่ขอ อนุมัติ จ่ายแล้ว สถานะรับของ และประวัติทุกขั้นตอน
4. คำขอสถานะ **แบบร่าง** หรือ **ส่งกลับแก้ไข** มีปุ่ม **แก้ไข**
5. คำขอสถานะ **แบบร่าง**, **รออนุมัติ** หรือ **ส่งกลับแก้ไข** ยกเลิกได้ โดยต้องระบุเหตุผล

คำขอที่ส่งกลับต้องเปิดดูเหตุผล แก้ข้อมูล แล้วกดส่งใหม่จึงจะกลับเข้าสู่คิวอนุมัติ

### 5.3 ยืนยันรับของ

1. เมื่อได้รับวัสดุ เข้าเมนู **ยืนยันรับของ**
2. ตรวจเลขใบจ่าย วันที่ รายการ จำนวน และชื่อผู้รับ
3. กด **ยืนยันว่าได้รับแล้ว** เฉพาะใบจ่ายที่ได้รับจริงและตรวจครบแล้ว
4. หากคำขอถูกจ่ายหลายครั้ง ต้องยืนยันทุกใบจ่าย

การยืนยันรับของไม่ตัดสต๊อกซ้ำ แต่เป็นหลักฐานปิดรับของ คำขอจะเสร็จสมบูรณ์ต่อเมื่อจ่ายครบหรือปิดยอดแล้ว และผู้เบิกยืนยันรับครบทุกใบจ่าย

### 5.4 พิมพ์ใบเบิก

เปิดคำขอแล้วกด **พิมพ์ใบเบิก A4** ระบบจะแสดงเอกสารตามรูปแบบที่ผู้ดูแลกำหนด จากนั้นกด **พิมพ์ / บันทึก PDF** และเลือกเครื่องพิมพ์หรือ **Save as PDF** ในเบราว์เซอร์

## 6. คู่มือสำหรับผู้อนุมัติ

### 6.1 พิจารณาคำขอ

1. เข้าเมนู **งานอนุมัติ → อนุมัติคำขอ**
2. คลิกเลขคำขอที่ต้องการ
3. ตรวจผู้เบิก กลุ่มงาน วัตถุประสงค์ รายการ จำนวนขอ และยอดคงเหลือขณะนั้น
4. กรอกจำนวนอนุมัติของแต่ละรายการ ค่าต้องไม่เกินจำนวนที่ขอ และกำหนดเป็นศูนย์ได้
5. เลือกผลการพิจารณา
   - **อนุมัติ**: ส่งงานต่อให้เจ้าหน้าที่พัสดุ
   - **ส่งกลับแก้ไข**: คืนให้ผู้เบิกแก้คำขอ ต้องระบุเหตุผล
   - **ไม่อนุมัติ**: จบคำขอโดยไม่จ่ายวัสดุ ต้องระบุเหตุผล

การอนุมัติไม่จองและไม่ตัดสต๊อก หากยอดไม่พอในวันจ่าย เจ้าหน้าที่พัสดุจะจ่ายได้ไม่เกินยอดจริง

### 6.2 ตรวจประวัติและพิมพ์

หน้ารายละเอียดคำขอแสดง Timeline ว่าใครทำอะไร เมื่อใด และมีเหตุผลหรือหมายเหตุใด ผู้อนุมัติสามารถพิมพ์ใบเบิก A4 และเปิดเมนูรายงานตามสิทธิ์ได้

## 7. คู่มือสำหรับเจ้าหน้าที่พัสดุ

### 7.1 จ่ายวัสดุ

1. เข้าเมนู **งานพัสดุ → จ่ายวัสดุ**
2. เปิดคำขอที่อนุมัติแล้วหรือจ่ายบางส่วน
3. หากจัดของเสร็จแล้ว สามารถกด **แจ้งพร้อมรับ** เพื่อส่ง LINE ถึงผู้เบิกที่ผูก LINE User ID ไว้
4. ในส่วน **ยืนยันจ่ายจริง** ตรวจจำนวนอนุมัติ จำนวนจ่ายสะสม และยอดคงเหลือ
5. กรอกจำนวน **จ่ายครั้งนี้** อย่างน้อยหนึ่งรายการ
6. กรอกชื่อผู้รับและหมายเหตุถ้ามี
7. กด **ยืนยันจ่ายและตัดสต๊อก** แล้วตรวจข้อความยืนยันก่อนดำเนินการ

ระบบไม่อนุญาตให้จำนวนจ่ายสะสมเกินจำนวนอนุมัติ ไม่อนุญาตให้สต๊อกติดลบ และป้องกันการกดจ่ายคำสั่งเดิมซ้ำ

หากจ่ายไม่ครบ คำขอจะเป็น **จ่ายบางส่วน** และกลับมาจ่ายเพิ่มได้ หากจะไม่จ่ายส่วนที่เหลือ ให้กรอกเหตุผลแล้วกด **ปิดคำขอ** ผู้เบิกยังต้องยืนยันใบจ่ายที่ได้รับจริง

### 7.2 เพิ่มและแก้ไขทะเบียนวัสดุ

เข้าเมนู **คลังวัสดุ** แล้วกด **เพิ่มวัสดุ** หรือคลิกชื่อวัสดุเดิมเพื่อแก้ไข ข้อมูลที่จัดเก็บประกอบด้วย

- รหัสวัสดุที่ไม่ซ้ำ
- ชื่อ หมวดหมู่ และรายละเอียด
- หน่วยพื้นฐาน เช่น ชิ้น ด้าม รีม หรือม้วน
- ยอดขั้นต่ำสำหรับแจ้งเตือนใกล้หมด
- ตำแหน่งจัดเก็บ
- รูป JPEG, PNG หรือ WebP ขนาดไม่เกิน 2 MB
- สถานะเปิดให้เบิก
- ตัวเลือก “ติดตามผู้รับไปใช้” สำหรับอุปกรณ์ใช้ซ้ำ

ยอดคงเหลือแก้จากหน้าทะเบียนไม่ได้ ต้องเปลี่ยนผ่านรับเข้า จ่าย คืน ตรวจนับ หรือกลับรายการ เพื่อให้ Ledger ครบถ้วน วัสดุที่มีประวัติควรปิดใช้งานแทนการลบ

### 7.3 รับวัสดุเข้าและบันทึกยอดตั้งต้น

ในหน้า **คลังวัสดุและรับเข้า** ไปที่ส่วน **รับเข้า / บันทึกยอดตั้งต้น** แล้วกรอก

1. วัสดุ
2. จำนวนในหน่วยพื้นฐาน
3. วันที่รับ
4. แหล่งที่มา เช่น ผู้ขาย หน่วยงาน หรือโครงการ
5. เอกสารอ้างอิง เช่น เลขใบส่งของ
6. ทำเครื่องหมาย **ยอดตั้งต้นจากการนับจริง** เฉพาะการเริ่มระบบหรือบันทึกยอดจากการนับตั้งต้น

หากซื้อเป็นบรรจุภัณฑ์ ให้แปลงก่อน เช่น 5 แพ็ก แพ็กละ 10 ด้าม ให้บันทึก 50 ด้าม

### 7.4 นำเข้าทะเบียนด้วย CSV

ใช้เมื่อต้องเพิ่มหรือปรับปรุงทะเบียนหลายรายการ

1. เปิดหน้านำเข้า CSV จากหน้าคลัง
2. ดาวน์โหลดแม่แบบ
3. กรอก `code`, `name`, `category`, `unit`, `minimum_qty`, `location`, `description`, `active` และ `track_assignee`
4. บันทึกเป็น **CSV UTF-8 (Comma delimited)** ขนาดไม่เกิน 2 MB
5. อัปโหลดและยืนยันนำเข้า

ระบบใช้ `code` เป็นกุญแจ: รหัสใหม่จะถูกเพิ่ม รหัสเดิมจะถูกปรับปรุง และทั้งไฟล์ทำงานภายใต้ transaction หากพบข้อผิดพลาดจะไม่บันทึกเพียงบางแถว การนำเข้าไม่เปลี่ยนยอดสต๊อก

### 7.5 คืนวัสดุ

1. เข้าเมนู **คืนวัสดุ**
2. เลือกรายการจ่ายที่ยังคืนไม่ครบ
3. ตรวจจำนวนที่จ่าย คืนแล้ว และคงเหลือที่คืนได้
4. กรอกจำนวน **สภาพดี** และ **ชำรุด** แยกกัน
5. กรอกชื่อผู้คืนและเหตุผล
6. ยืนยันการคืน

ของสภาพดีจะเพิ่มกลับเข้าสต๊อก ของชำรุดจะเก็บเป็นประวัติแต่ไม่เพิ่มยอดพร้อมเบิก หากวัสดุเปิด “ติดตามผู้รับไปใช้” ยอดคงค้างของผู้รับจะลดลงตามจำนวนคืนทั้งหมด

### 7.6 ตรวจนับวัสดุ

1. เข้าเมนู **ตรวจนับ**
2. เลือกวัสดุที่ต้องการและใส่หมายเหตุ
3. กด **สร้างรอบ** ระบบจะบันทึกยอดและเวอร์ชัน ณ เวลานั้น
4. เปิดเลขรอบตรวจนับ
5. กรอกยอดจริงของแต่ละรายการ
6. หากยอดต่างจากระบบ ต้องระบุเหตุผล
7. กด **ยืนยันผลตรวจนับ**

หากมีการรับ จ่าย คืน หรือ movement อื่นระหว่างสร้างรอบกับยืนยัน ระบบจะแสดงว่า “มีการเคลื่อนไหวแล้ว” และไม่ยอมปรับยอด เพื่อป้องกันการทับข้อมูล ให้สร้างรอบใหม่จากยอดล่าสุด

### 7.7 ตรวจความถูกต้องของสต๊อก

เมนู **ตรวจสอบความถูกต้องสต๊อก** เปรียบเทียบ 3 ค่า ได้แก่ ยอดปัจจุบัน ผลรวม Stock Movement Ledger และยอดหลัง Movement ล่าสุด พร้อมแสดงผลต่าง

- หากขึ้น **ถูกต้อง** แสดงว่ายอดตรงกัน
- หากขึ้น **ต้องตรวจสอบ** ให้เปิดรายงานเคลื่อนไหว ตรวจเอกสารอ้างอิง และแก้ด้วยการกลับรายการหรือตรวจนับ
- ห้ามแก้ `stock_qty` หรือ Ledger โดยตรงในฐานข้อมูล
- สามารถกด **ส่งออก CSV** เพื่อเก็บผลการกระทบยอด

### 7.8 กลับรายการที่บันทึกผิด

ในเมนู **รายงาน → เคลื่อนไหว** เจ้าหน้าที่พัสดุสามารถกรอก ID ของ movement และเหตุผลเพื่อสร้างรายการกลับรายการ ระบบจะไม่ลบข้อมูลเดิม แต่สร้าง movement ตรงข้ามเพื่อคงร่องรอยตรวจสอบ

ไม่สามารถกลับ “รายการกลับรายการ” ซ้ำได้ หลังดำเนินการควรเปิดหน้าตรวจความถูกต้องของสต๊อกอีกครั้ง

## 8. รายงานและการพิมพ์

ผู้มีบทบาทเจ้าหน้าที่พัสดุ ผู้อนุมัติ หรือผู้ดูแลเข้าถึงเมนู **รายงาน** ได้

### 8.1 ประเภทรายงาน

| รายงาน | เนื้อหาและการใช้งาน |
|---|---|
| ยอดคงเหลือ | ทะเบียนทั้งหมด ยอดปัจจุบัน ยอดขั้นต่ำ ตำแหน่ง และสถานะ |
| ต่ำกว่ายอดขั้นต่ำ | วัสดุเปิดใช้งานที่ยอดน้อยกว่าหรือเท่ากับจุดขั้นต่ำ |
| เคลื่อนไหว | รับเข้า จ่าย คืน ตรวจนับ และกลับรายการ พร้อมยอดหลังรายการ ผู้บันทึก และเอกสารอ้างอิง |
| การเบิก | เลขคำขอ ผู้เบิก กลุ่มงาน วัสดุ จำนวนขอ อนุมัติ และจ่ายจริง |
| อุปกรณ์ใช้ซ้ำ | รายการที่เปิดติดตามผู้รับ และยังมีจำนวนคงค้างอยู่กับผู้ใช้ |
| เชิงบริหาร | KPI แนวโน้มรายเดือน วัสดุใช้มาก กลุ่มงาน การใช้เพิ่มผิดปกติ และประมาณการวันหมด |

รายงานเคลื่อนไหวกรองได้ตามวันที่และวัสดุ รายงานการเบิกกรองได้ตามวันที่ วัสดุ ผู้เบิก และกลุ่มงาน ข้อมูลตารางบนหน้าจอจำกัดสูงสุด 1,000 แถว ควรกำหนดช่วงวันที่เมื่อข้อมูลมีจำนวนมาก

### 8.2 รายงานเชิงบริหาร

เลือกช่วงวันที่แล้วกด **ประมวลผล** ระบบสรุปจากจำนวนจ่ายจริง ไม่ใช่จำนวนขอหรืออนุมัติ โดยแสดง

- จำนวนคำขอที่มีการจ่าย จำนวนใบจ่าย จำนวนรายการ และจำนวนกลุ่มงาน
- แนวโน้มจำนวนใบจ่ายรายเดือน
- วัสดุที่ใช้มากที่สุดและจำนวนคำขอที่เกี่ยวข้อง
- การใช้งานแยกกลุ่มงาน
- วัสดุที่ใช้เพิ่มขึ้นอย่างน้อย 50% เมื่อเทียบ 30 วันล่าสุดกับ 30 วันก่อนหน้า
- ประมาณการจำนวนวันที่ของจะหมดจากอัตราจ่ายเฉลี่ย 90 วัน

ค่าประมาณเป็นข้อมูลเพื่อวางแผน ไม่ใช่การจองของหรือคำสั่งซื้อ

### 8.3 CSV และ PDF

- กด **ส่งออก CSV** หรือ **ส่งออก CSV ตามตัวกรอง** เพื่อเปิดใน Excel
- ไฟล์ CSV ใช้ UTF-8 BOM และป้องกันค่าที่ Excel อาจตีความเป็นสูตร
- รายงานเชิงบริหารและใบเบิกใช้คำสั่งพิมพ์ของเบราว์เซอร์เพื่อพิมพ์หรือ Save as PDF
- ผู้ดูแลสามารถกำหนดโลโก้ ข้อความหัว/ท้าย ชื่อผู้จัดทำ/ผู้ตรวจสอบ และแนวกระดาษของรายงานได้

## 9. คู่มือสำหรับผู้ดูแลระบบ

เมนูตั้งค่าระบบแบ่งตามงาน เพื่อป้องกันแบบฟอร์มยาวและลดความผิดพลาด

### 9.1 ชื่อและโลโก้

กำหนดชื่อระบบ ชื่อสำนักงาน คำนำหน้าเลขคำขอ โทนสี และโลโก้ได้ รองรับ JPEG, PNG และ WebP ไม่เกิน 2 MB และขนาดภาพไม่เกิน 4,000 × 4,000 พิกเซล การเปลี่ยนคำนำหน้ามีผลกับเลขคำขอใหม่ ไม่เปลี่ยนเลขเดิม

### 9.2 เมนูและรายงาน

- เปลี่ยนชื่อเมนู เปิด/ปิดการแสดง และกำหนดลำดับภายในหมวด
- เมนูภาพรวมและเมนูตั้งค่าเมนู/รายงานถูกบังคับให้แสดง
- การซ่อนเมนูไม่ถอนสิทธิ์ของบทบาท
- กำหนดข้อความหัว/ท้ายรายงาน ชื่อช่องผู้จัดทำ/ผู้ตรวจสอบ โลโก้ และแนวกระดาษได้

### 9.3 รูปแบบใบเบิก

กำหนดชื่อเอกสาร ข้อความใต้ชื่อสำนักงาน ข้อความก่อนรายละเอียดและท้ายเอกสาร ชื่อช่องข้อมูล ชื่อคอลัมน์ ช่องลงนาม การแสดงโลโก้ และการแสดงสถานะได้ หากมีคำขอในระบบ จะมีปุ่มดูตัวอย่างจากคำขอล่าสุด

### 9.4 บัญชีผู้ใช้

การสร้างบัญชีต้องระบุชื่อผู้ใช้ ชื่อ-สกุล รหัสผ่านอย่างน้อย 6 ตัวอักษร กลุ่มงาน และอย่างน้อยหนึ่งบทบาท สามารถเลือกหลายบทบาทและเพิ่ม LINE User ID ได้

การแก้ไขบัญชีสามารถเปลี่ยนชื่อ กลุ่มงาน LINE บทบาท สถานะ และรหัสผ่าน โดยเว้นช่องรหัสผ่านเพื่อคงค่าเดิม ระบบไม่ยอมให้ผู้ดูแลปิดบัญชีของตนเองหรือถอนสิทธิ์ admin จากบัญชีที่กำลังใช้งาน และต้องมีผู้ดูแลที่เปิดใช้งานอย่างน้อยหนึ่งบัญชีเสมอ

บัญชีที่มีประวัติควรเอาเครื่องหมาย **เปิดใช้งาน** ออกแทนการลบ เพื่อรักษาความเชื่อมโยงของเอกสารและ Audit Log

### 9.5 กลุ่มงาน

ใช้สร้างหน่วยงานหรือฝ่ายของผู้เบิก กลุ่มงานจะติดไปกับคำขอและใช้กรองรายงาน ผู้ดูแลควรตั้งชื่อให้ไม่ซ้ำและเป็นรูปแบบเดียวกันก่อนสร้างบัญชีผู้ใช้

### 9.6 QR Code เข้าใช้งาน

ระบบสร้าง QR Code จาก `base_url` ที่ตั้งในไฟล์ configuration ผู้ใช้มือถือสแกนเพื่อเปิดระบบได้ แต่ยังต้องเข้าสู่ระบบตามปกติ หาก QR เปิดไม่ได้ ให้ตรวจว่า `base_url` เป็น IP หรือชื่อเครื่องที่มือถือเข้าถึงได้ และมือถืออยู่ในเครือข่ายเดียวกัน

## 10. การแจ้งเตือน LINE

ระบบใช้ LINE Official Account + Messaging API ไม่ใช่ LINE Notify และรองรับเหตุการณ์ต่อไปนี้

- ส่งคำขอใหม่ถึงรายชื่อเจ้าหน้าที่ที่ตั้งไว้
- แจ้งผู้เบิกเมื่ออนุมัติ ส่งกลับ หรือไม่อนุมัติ
- แจ้งผู้เบิกเมื่อพัสดุพร้อมรับและเมื่อมีการจ่าย
- ส่งสรุปคำขอรออนุมัติ รอจ่าย และรอยืนยันรับที่เกินกำหนด
- ส่งสรุปวัสดุต่ำกว่ายอดขั้นต่ำจากงาน maintenance

### 10.1 ตั้งค่า

1. ตั้ง Channel Access Token ใน environment หรือไฟล์ configuration ของเซิร์ฟเวอร์
2. ให้ผู้รับเพิ่ม LINE Official Account ของสำนักงานเป็นเพื่อน
3. เข้า **ตั้งค่าระบบ → แจ้งเตือน LINE**
4. ใส่ LINE User ID ของเจ้าหน้าที่หนึ่งบัญชีต่อบรรทัด สูงสุด 20 บัญชี รูปแบบเป็น `U` ตามด้วยอักขระฐานสิบหก 32 ตัว
5. บันทึก แล้วกด **ส่งข้อความทดสอบ**
6. เมื่อทดสอบสำเร็จ จึงเปิดการแจ้งเตือน

LINE User ID ไม่ใช่ LINE ID ที่ใช้ค้นหาเพื่อน และ Token จะไม่แสดงกลับบนหน้าจอ

### 10.2 แจ้งเตือนงานค้าง

กำหนดจำนวนวันรออนุมัติ รอจ่าย และรอยืนยันรับได้ตั้งแต่ 1–90 วัน แล้วเปิด **แจ้งเตือนงานค้างตามเวลา** งานนี้ต้องมี Windows Task Scheduler เรียก maintenance วันละครั้ง ระบบป้องกันการส่งสรุปของวันเดียวกันซ้ำ

### 10.3 ตรวจผลการส่ง

ส่วน **ประวัติส่งล่าสุด** แสดงเวลา เลขคำขอ ผู้รับแบบปกปิดบางส่วน สถานะ HTTP และข้อความผิดพลาด หาก LINE ส่งไม่สำเร็จ รายการธุรกิจ เช่น การส่งคำขอหรือการจ่าย ยังคงบันทึกสำเร็จ ระบบจะแจ้งเตือนบนหน้าเว็บให้ติดต่อผู้เกี่ยวข้องทางอื่น

### 10.4 ผู้เบิกเชื่อมต่อ LINE ด้วยตนเอง

เมื่อผู้ดูแลตั้ง Webhook เรียบร้อย ผู้เบิกไม่ต้องค้นหา LINE User ID ด้วยตนเอง:

1. เพิ่ม LINE Official Account ของสำนักงานเป็นเพื่อน
2. เข้าระบบแล้วเปิดเมนู **เชื่อมต่อ LINE**
3. กด **สร้างรหัสเชื่อมต่อ**
4. ส่งข้อความ `ลงทะเบียน` ตามด้วยรหัส 8 ตัวที่หน้าจอแสดงไปยัง Official Account
5. LINE ตอบว่าเชื่อมต่อสำเร็จ แล้วหน้าเว็บจะแสดงสถานะเมื่อเปิดใหม่

รหัสมีอายุ 15 นาที ใช้ได้ครั้งเดียว และไม่ควรส่งให้บุคคลอื่น ผู้เบิกสามารถยกเลิกการเชื่อมต่อจากหน้าเดียวกันได้ LINE หนึ่งบัญชีผูกกับบัญชีระบบได้เพียงบัญชีเดียว

สำหรับผู้ดูแล Webhook URL คือ `{base_url}/line-webhook.php` และต้องเป็น HTTPS สาธารณะที่ LINE เข้าถึงได้ เซิร์ฟเวอร์จะตรวจลายเซ็นด้วย `LINE_CHANNEL_SECRET` ก่อนประมวลผลทุกครั้ง

## 11. ความหมายของสถานะ

| สถานะ | ความหมาย | ผู้ดำเนินการถัดไป |
|---|---|---|
| แบบร่าง | บันทึกแล้วแต่ยังไม่ส่ง | ผู้เบิกแก้ไขหรือส่งคำขอ |
| รออนุมัติ | ส่งให้ผู้อนุมัติแล้ว | ผู้อนุมัติ |
| ส่งกลับแก้ไข | ผู้อนุมัติขอข้อมูลเพิ่มเติมหรือแก้ไข | ผู้เบิก |
| อนุมัติแล้ว | อนุมัติและรอจัดจ่าย | เจ้าหน้าที่พัสดุ |
| ไม่อนุมัติ | คำขอสิ้นสุดโดยไม่จ่าย | ไม่มี |
| ยกเลิก | ผู้เบิกยกเลิกก่อนเข้าสู่ขั้นจ่าย | ไม่มี |
| จ่ายบางส่วน | จ่ายแล้วบางรายการหรือบางจำนวน | เจ้าหน้าที่พัสดุจ่ายเพิ่มหรือปิดยอด |
| จ่ายครบ · รอยืนยันรับ | ตัดสต๊อกครบแล้ว แต่ผู้เบิกยังยืนยันใบจ่ายไม่ครบ | ผู้เบิก |
| ปิดยอด · รอยืนยันรับ | ปิดจำนวนที่เหลือแล้ว แต่ยังยืนยันใบจ่ายไม่ครบ | ผู้เบิก |
| เสร็จสมบูรณ์ | จ่ายเสร็จหรือปิดยอด และยืนยันรับครบแล้ว | ไม่มี |

สถานะรับของมี 3 แบบ: **ยังไม่ยืนยัน**, **รับบางส่วน** และ **รับครบ** ซึ่งแยกจากสถานะการอนุมัติ/จ่าย

## 12. ข้อควรระวังและคำถามที่พบบ่อย

### ทำไมอนุมัติแล้วแต่ยอดยังไม่ลด

ถูกต้องตามการออกแบบ ระบบตัดสต๊อกเมื่อเจ้าหน้าที่พัสดุยืนยันจ่ายจริง ไม่ตัดตอนอนุมัติ

### ทำไมส่งคำขอไม่ได้ทั้งที่บันทึกแบบร่างได้

ยอดวัสดุอาจหมดหลังบันทึกแบบร่าง หรือไม่มีรายการในคำขอ ให้เปิดแก้ไขและตรวจวัสดุ/จำนวนอีกครั้ง

### ทำไมคำขอยังไม่เสร็จทั้งที่จ่ายครบแล้ว

ผู้เบิกยังไม่ได้ยืนยันรับของครบทุกใบจ่าย ให้เข้าเมนู **ยืนยันรับของ**

### ทำไมยืนยันตรวจนับไม่ได้

มีการเคลื่อนไหวของวัสดุหลังสร้างรอบตรวจนับ ให้สร้างรอบใหม่เพื่อใช้ยอดตั้งต้นล่าสุด

### แก้ยอดผิดอย่างไร

ห้ามแก้ฐานข้อมูลตรง หากเป็น movement ผิดให้ใช้กลับรายการ หากยอดจริงไม่ตรงให้สร้างรอบตรวจนับและระบุเหตุผล

### ทำไมไม่เห็นเมนู

บัญชีอาจไม่มีบทบาทที่เกี่ยวข้อง เมนูอาจถูกซ่อนในการตั้งค่า หรือหน้าจอมือถือพับแถบเมนูไว้ ให้กดปุ่มเมนูและติดต่อผู้ดูแลหากยังไม่พบ

### LINE ไม่ส่ง แต่รายการบันทึกสำเร็จหรือไม่

สำเร็จ การส่ง LINE แยกจาก transaction ของงานหลัก ตรวจข้อความเตือนและประวัติการส่ง แล้วแจ้งผู้เกี่ยวข้องด้วยช่องทางอื่น

### แนวทางใช้งานที่ปลอดภัย

- ตรวจเลขคำขอ วัสดุ จำนวน และชื่อผู้รับก่อนกดยืนยัน
- ใช้หน่วยพื้นฐานเดียวกันทั้งทะเบียน รับเข้า เบิก และตรวจนับ
- ไม่ใช้บัญชีร่วมกัน เพราะระบบบันทึกชื่อผู้ดำเนินการทุกขั้นตอน
- ปิดบัญชีหรือวัสดุที่เลิกใช้แทนการลบประวัติ
- ออกจากระบบทุกครั้งเมื่อใช้เครื่องสาธารณะ
- ตรวจรายงาน Ledger และหน้าความถูกต้องของสต๊อกเป็นประจำ
- สำรองฐานข้อมูลและไฟล์อัปโหลดตามรอบที่หน่วยงานกำหนด
