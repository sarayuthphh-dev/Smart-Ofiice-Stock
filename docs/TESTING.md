# แผนตรวจรับระบบ

รัน `php tests/integration.php` กับฐานข้อมูลทดสอบตาม README ก่อน แล้วตรวจผ่านหน้าจอด้วยบัญชีแยกบทบาทดังนี้

1. ตั้งยอดกระดาษ A4 เป็น 50 รีม สร้าง/อนุมัติ/จ่าย 3 รีม ตรวจหน้า dashboard, materials และ ledger ว่าเหลือ 47
2. หลังอนุมัติแต่ก่อนจ่าย ตรวจว่ายังเป็น 50
3. อนุมัติ 10 จ่าย 4 แล้ว 6 ได้; ทดลองจ่ายอีก 1 ต้องถูกปฏิเสธ
4. ทดลองจ่ายมากกว่ายอดคงเหลือ ต้องไม่เกิด issue/movement และยอดไม่เปลี่ยน
5. ดับเบิลคลิก/ส่ง POST idempotency key เดิม ต้องมี issue เดียวและ movement เดียว
6. integration test เปิด worker สอง process จ่ายรายการละ 4 จากยอด 5 ต้องสำเร็จหนึ่งรายการ ล้มเหลวหนึ่งรายการ และเหลือ 1
7. คืนจากเอกสารจ่ายเดิม: ดี 1 ชำรุด 1 ยอดคลังเพิ่มเพียง 1 และคืนสะสมเกินจำนวนจ่ายไม่ได้
8. ล็อกอินแต่ละบทบาท ตรวจเมนูและลอง URL ตรง ผู้เบิก A เปลี่ยน `id` เป็นคำขอของ B ต้องได้ 403/ไม่พบ
9. สร้างรอบตรวจนับ แล้วรับเข้าหรือจ่ายวัสดุนั้นก่อนยืนยัน ระบบต้องแจ้งให้สร้างรอบใหม่และไม่ปรับยอดทับ
10. เปิดใบเบิก Print Preview ขนาด A4 ตรวจหัวเรื่อง ตารางและลายเซ็นไม่ตัดแถว; เปิด CSV ด้วย Excel ตรวจภาษาไทย และสร้างชื่อทดสอบขึ้นต้น `=`, `+`, `-`, `@` เพื่อตรวจว่าถูกนำหน้าด้วย apostrophe
11. ดาวน์โหลดแม่แบบจากหน้า **นำเข้า CSV** เพิ่มรหัสใหม่หนึ่งรายการและแก้ชื่อรหัสเดิมหนึ่งรายการ ตรวจว่านำเข้าสำเร็จทั้งคู่และยอดคงเหลือเดิมไม่เปลี่ยน; ทดลองหัวตารางผิด/รหัสซ้ำในไฟล์ ต้องยกเลิกทั้งไฟล์
12. หน้า **รายงาน** เปิด PDF การเพิ่มวัสดุและ PDF การเบิก/จ่าย ตรวจว่าตัวกรองถูกส่งต่อ ตารางไม่ตัดแถว และ Chrome/Edge สามารถ Save as PDF ขนาด A4 แนวนอนได้
13. ตั้ง Channel Access Token และ LINE User ID ทดสอบใน **ตั้งค่าระบบ → แจ้งเตือน LINE** กดส่งข้อความทดสอบ ตรวจว่าได้รับในแชตส่วนตัว จากนั้นส่งคำขอเบิกใหม่และตรวจเลขคำขอ ผู้เบิก รายการ และลิงก์ ทดลองส่ง POST เดิมซ้ำต้องไม่มีข้อความซ้ำ ปิดอินเทอร์เน็ตชั่วคราวแล้วส่งคำขอเพื่อตรวจว่าคำขอยังบันทึกสำเร็จและประวัติ LINE แสดง “ส่งไม่สำเร็จ”
14. เข้าด้วยผู้ดูแล เปิด **ตั้งค่าระบบ → รูปแบบใบเบิก** เปลี่ยนชื่อเอกสาร ป้ายคอลัมน์ ช่องลงนาม ข้อความหัว/ท้าย และเปิด/ปิดโลโก้กับสถานะ จากนั้นเปิดตัวอย่างคำขอล่าสุด ตรวจ Print Preview A4 ว่าค่าใหม่แสดงครบและตารางไม่ถูกตัดผิดตำแหน่ง

บันทึกวันเวลา ผู้ทดสอบ browser/PHP/MariaDB ที่ใช้ และหลักฐานผลจริงทุกข้อ ห้ามใช้ฐานข้อมูล production รัน integration test เพราะสคริปต์ล้างตารางในฐาน `_test`
